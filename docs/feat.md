# FEATURE

1. 支持分组（pinned 和其他区分）
   - 平铺模式
   - 分组模式（按 tag 分组，同个项目不同 tag 可以多次出现）
2. 支持 tag 筛选（pinned 和其他区分）
   - 仅做筛选功能
   - 单项目支持多 tag
3. 支持默认打开方式配置
4. 支持网络仓库搜索
   - 多仓库搜索/配置
   - clone 到本地
   - 仅收藏
5. 支持添加自定义 IDE 启动命令
6. 支持 lisence 状态图标
7. 强制添加项目文件夹
8. Tray 场景开发
   - 关闭最小化在托盘
   - 退出
9. 安装包选项配置研究
10. 项目整体迁移 ts 框架开发
11. 安装包路径展示及打开清理
12. 开机自动运行
13. 自动更新的配置
14. 开发模式下增加 console 打开按钮 ✔
15. vitepress 使用文档及 github pages 部署
16. 复制项目（默认复制到同个父级文件夹+自动命名后缀）
17. 重命名文件夹名
18. 指定项目名规则（projectName 或者 fileName 或者 projectName>fileName 或者 fileName>projectName）
19. 收藏夹 Collection 功能
    - 本地 pinned 项目
    - 网络上的收藏项目
20. 多开限制，只能开一个app
