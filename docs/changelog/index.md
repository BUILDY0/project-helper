# 更新日志

所有版本对应的安装包可在 [GitHub Releases](https://github.com/BUILDY0/project-helper/releases) 下载。

## v1.2.1

> 发布时间：2026-05-28

- 删除项目文件夹支持 **软删除 / 硬删除** 区分。
- 设置页新增 **帮助** 模块。
- 设置页中的 **主题风格** 配置项已移除，主题切换统一在标题栏完成（v1.2.0 已支持），不再需要保存配置。
- 「重置扫描深度」改为直接生效，不再弹出二次确认。
- 限制单应用运行

## v1.2.0

> 发布时间：2026-05-26

- 新增 **深色主题**：标题栏增加主题切换按钮，支持浅色 / 深色主题。
- 鼠标悬浮提示优化。
- 自动更新提示中新增 **「新改动！」** 入口，可一键打开当前版本的更新说明。
- 滚动条宽度收窄，整体观感更紧凑。

## v1.1.4

> 发布时间：2026-05-25

- 图标整体尺寸加大。
- 项目卡片悬浮时不再溢出边缘；滚动条改为不贴底。
- 目录扫描方式：改为并行执行，相比上一版有明显的速度提升。
- 开发者模式下，增加 Console 入口按钮，便于排查问题（普通用户可忽略）。

## v1.1.3

> 发布时间：2026-05-23

- 默认 IDE 探测列表精简，移除暂未支持的 JetBrains 系列。
- 修正 Trae 中文版的命令名识别，现在能正确通过 Trae 打开项目。

## v1.1.2

> 发布时间：2026-05-23

- 右键菜单底部说明文字居中显示，视觉更整齐。

## v1.1.1

> 发布时间：2026-05-23

- 修正项目列表刷新图标的旋转方向。

## v1.1.0

> 发布时间：2026-05-23

- 支持状态图标展示：
  - github：git初始化同步远端的项目，点击后跳转到项目页
  - nodejs：nodejs技术栈的项目，点击后打开项目文件夹
  - readme: 项目内包含readme.md文件，点击后打开readme文件

## v1.0.1

> 发布时间：2026-05-22

- 支持 **多 IDE 启动**：在右键菜单中可选择不同的 IDE 打开项目。
- 右键菜单新增 **复制路径** 与 **属性** 对话框，方便快速取用项目路径与基本信息。
- 没有 `package.json` 的项目，项目描述读取 README 首段作为兜底显示。
- 自动更新失败时不再弹出原生报错框，改为静默处理，不打扰使用。

## v1.0.0

> 发布时间：2026-05-22

**首个公开版本**，核心能力：

- 一次配置多个根目录，自动扫描并展示所有本地项目。
- 项目卡片展示项目名、路径与简介，支持搜索定位。
- **置顶**常用项目，**排除**不需要的目录，列表更清爽。
- 一键使用 VSCode 打开项目，或通过右键菜单调用其他操作。
- 配置页可视化编辑扫描目录、扫描深度、排除项与置顶项；切换tab时若有未保存修改会提示确认。
- 内置自动更新：发现新版本会在右下角提示，点击即可下载安装。
- 提供 Windows NSIS 安装包，可自定义安装目录。
