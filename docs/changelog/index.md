# 更新日志

所有版本对应的安装包可在 [GitHub Releases](https://github.com/BUILDY0/project-helper/releases) 下载。

## v1.1.4

> 发布时间：2026-05-25

- 应用图标、操作栏图标整体加大，识别度更高。
- 项目卡片悬浮时不再溢出边缘；列表底部留出更舒服的滚动空间。
- 大目录扫描更快：相比上一版有明显的速度提升。
- 开发者模式下，卡片支持一键打开 Console，便于排查问题（普通用户可忽略）。

## v1.1.3

> 发布时间：2026-05-23

- 默认 IDE 探测列表精简，移除暂未支持的 JetBrains 系列。
- 修正 Trae 中文版的命令名识别，现在能正确通过 Trae 打开项目。

## v1.1.2

> 发布时间：2026-05-23

- 右键菜单底部说明文字居中显示，视觉更整齐。

## v1.1.1

> 发布时间：2026-05-23

- 修正项目列表刷新图标的旋转方向。

## v1.1.0

> 发布时间：2026-05-23

- 项目卡片新增 **打开 README** 按钮，无需进入 IDE 即可快速查看项目说明。
- 卡片展示更丰富的项目信息：**Git 仓库状态** 与 **Node.js 版本**，并支持点击查看详情。

## v1.0.1

> 发布时间：2026-05-22

- 支持 **多 IDE 启动**：在右键菜单中可选择不同的 IDE 打开项目。
- 右键菜单新增 **复制路径** 与 **属性** 对话框，方便快速取用项目路径与基本信息。
- 没有 `package.json` 的项目，自动从 README 首段读取描述作为兜底显示。
- 自动更新失败时不再弹出原生报错框，改为静默处理，不打扰使用。

## v1.0.0

> 发布时间：2026-05-22

**首个公开版本**，核心能力：

- 一次配置多个根目录，自动扫描并展示所有本地项目。
- 项目卡片展示项目名、路径与简介，支持搜索定位。
- **置顶**常用项目，**排除**不需要的目录，列表更清爽。
- 一键使用 VSCode 打开项目，或通过右键菜单调用其他操作。
- 配置页可视化编辑扫描目录、扫描深度、排除项与置顶项；离开页面时若有未保存修改会提示确认。
- 内置自动更新：发现新版本会在右下角提示，点击即可下载安装。
- 提供 Windows NSIS 安装包，可自定义安装目录。
