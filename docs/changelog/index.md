# 更新日志

所有版本对应的安装包可在 [GitHub Releases](https://github.com/BUILDY0/project-helper/releases) 下载。

## v1.5.2

> 发布时间：2026-06-06

- 项目卡片置顶按钮改为 **Fluent UI 图钉图标**。
- 修复 **默认 IDE 设置**清除选项按钮异常展示的问题。

## v1.5.1

> 发布时间：2026-06-05

- 修复托盘图标加载失败的问题。

## v1.5.0

> 发布时间：2026-06-05

- 支持 **系统托盘**：可快速打开项目，退出可选隐藏至托盘。
- 支持 **自定义 IDE 配置**：可设置默认启动 IDE 及自定义 IDE 入口，灵活适配多种开发工具。
- 新增 **自动清理安装包缓存** 功能，安装更新后旧安装包可自动清理，节省磁盘空间。
- 项目列表新增 **新增扫描目录** 快捷入口。
- 设置页扫描相关选项整合为单一卡片，界面更简洁。
- 关于对话框新增运行时信息（Electron / Node / Chrome 版本）。
- tooltip 移除箭头元素，视觉更简洁。

## v1.4.0

> 发布时间：2026-06-01

- 右键菜单新增 **复制父级路径**，一键取用项目所在目录的路径。
- 右键菜单新增 **打开项目父级文件夹**，可直接定位到项目的上层目录。
- 项目卡片新增 **文件夹重命名** 功能，直接在列表中改名更顺手。
- 项目描述改为读取 README 前三行；悬浮提示支持 **Markdown 轻量渲染**，预览更直观。
- 项目名称直接使用文件名，不再依据项目依赖文件判断。

## v1.3.0

> 发布时间：2026-05-30

- 升级到 **Electron 34 / Node 22**，整体运行时与构建链同步更新。
- 设置页新增 **开机自启** 开关：开启后随系统启动自动打开应用。
- 设置页新增 **自动检查更新** 开关与 **手动检查更新** 按钮，可按需控制更新策略。
- 扫描目录新增 **强制命中** 开关（`paths[].cfg.forced`）：开启后，即使目录不含 `.git` 或 `package.json` 也会作为项目卡片显示，便于把脚本目录、文档目录纳入列表。
- 添加项目目录时支持 **目录与文件多选**，一次配置更高效。
- 删除项目目录时增加 **二次确认**，避免误删。
- 顶部 Banner 支持根据当前主题自动切换 **浅色 / 深色** 版本的配图。
- 新增 **zip 与 NSIS** 双格式 Windows 打包脚本（`build:zip` / `build:nsis`），按需选择安装包形态。

## v1.0.1

> 发布时间：2026-05-22

- 支持 **多 IDE 启动**：在右键菜单中可选择不同的 IDE 打开项目。
- 右键菜单新增 **复制路径** 与 **属性** 对话框，方便快速取用项目路径与基本信息。
- 没有 `package.json` 的项目，项目描述读取 README 首段作为兜底显示。
- 自动更新失败时不再弹出原生报错框，改为静默处理，不打扰使用。

## v1.0.0

> 发布时间：2026-05-22

**首个公开版本**，核心能力：

- 一次配置多个根目录，自动扫描并展示所有本地项目。
- 项目卡片展示项目名、路径与简介，支持搜索定位。
- **置顶**常用项目，**排除**不需要的目录，列表更清爽。
- 一键使用 VSCode 打开项目，或通过右键菜单调用其他操作。
- 配置页可视化编辑扫描目录、扫描深度、排除项与置顶项；切换tab时若有未保存修改会提示确认。
- 内置自动更新：发现新版本会在右下角提示，点击即可下载安装。
- 提供 Windows NSIS 安装包，可自定义安装目录。
