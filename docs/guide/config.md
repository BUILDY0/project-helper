# 配置

Project Helper 的所有持久化配置均保存在用户目录下的一个 JSON 文件中，应用启动时读取，保存时写回。

## 配置文件位置

```
%USERPROFILE%\.project-helper\config.json
```

可在应用「配置」页点击 **打开文件** / **打开文件夹** 直接定位。

## 字段说明

```json
{
  "paths": ["D:/work"],
  "depth": 1,
  "exclude_paths": ["D:/work/legacy"],
  "pinned": ["D:/work/my-favorite-project"]
}
```

| 字段            | 类型       | 默认 | 说明                                           |
| --------------- | ---------- | ---- | ---------------------------------------------- |
| `paths`         | `string[]` | `[]` | 扫描根目录列表，可配置多个                     |
| `depth`         | `number`   | `1`  | 扫描深度，范围 `0 - 5`                         |
| `exclude_paths` | `string[]` | `[]` | 排除目录列表，命中即跳过整棵子树               |
| `pinned`        | `string[]` | `[]` | 置顶项目的绝对路径，扫描时会自动清理已失效的项 |

## 扫描深度

- `0`：仅识别 `paths` 自身是否是项目目录。
- `1`（默认）：扫描 `paths` 的直接子目录。
- `2 ~ 5`：递归向下扫描更深层级，深度越大耗时越长，请按需调整。

## 排除目录

任一被扫描到的路径，只要它本身或其父级匹配 `exclude_paths` 中的任一项，整棵子树都不会被遍历。

适合用于：

- 跳过体积较大的归档目录（如 `legacy`、`archive`）。
- 跳过临时性目录（如 `tmp`、`sandbox`）。

## 置顶项目

- 在项目列表中右键 → 置顶，会写入 `pinned`。
- 重新扫描时，已不存在（被删除或挪走）的置顶路径会被自动清理。
- 也可在「配置」页直接移除单项 / 一键清空。

## 保存与生效

- 所有改动需点击右上角 **保存** 才会写入磁盘。
- 在「项目」与「配置」两个 Tab 之间切换时，如有未保存的修改会弹窗提示。
- 保存成功后会重新加载并刷新「最后修改时间」。
