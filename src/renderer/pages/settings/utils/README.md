# utils

仅 **settings 页内**复用的纯函数集合。

> 升格规则：当某个函数被**第二个页面 / 组件**用到时，应该上移到 `src/renderer/utils/`。

## 现有内容

| 文件             | 说明                                                         |
| ---------------- | ------------------------------------------------------------ |
| `path-helper.js` | 扫描目录项的归一化助手（兼容旧版字符串与新 SystemPath 对象） |
